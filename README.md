# Airport Flight Management System

## Overview

This project was developed as part of the Data Structures course.

It implements an Airport Flight Management System in C using Linked Lists and Queues to manage flights, passengers, arrivals, departures, and emergency flights. Flight and passenger information is loaded from external text files.

---

## Features

- Load flight information from file
- Load passenger information from file
- Search for a flight by ID
- Display complete flight details
- Add new flights
- Cancel flights
- Land arriving and emergency flights
- Depart scheduled flights
- Manage passengers
  - View passengers
  - Add passengers
  - Remove passengers
- Display current airport status

---

## Data Structures

- Singly Linked Lists
- Queues
- Dynamic Memory Allocation
